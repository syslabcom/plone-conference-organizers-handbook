# Euregio contact kit

This kit turns one qualified CSV route into one permission-first contact and one agreed follow-up. Start with [`../MAKING_CONTACT.md`](../MAKING_CONTACT.md).

## Which file to use

| Need | Module |
|---|---|
| Qualify a route and prepare a call | [`PITCH_TEMPLATE.md`](PITCH_TEMPLATE.md) |
| Record a detailed call and next action | [`CALL_RECORD.md`](CALL_RECORD.md) |
| Send the agreed handout and summary | [`FOLLOW_UP.md`](FOLLOW_UP.md) (Attach the correct PDF from [`handouts/`](handouts/)) |
| Give a multiplier approved copy to share | [`MULTIPLIER_FORWARDING.md`](MULTIPLIER_FORWARDING.md) |
| Invite a person whose contact is welcome | [`DIRECT_INVITATION.md`](DIRECT_INVITATION.md) |
| Answer likely practical questions | [`FAQ.md`](FAQ.md) |
| See a worked Dutch public-sector route | [`examples/NL-PL-01.md`](examples/NL-PL-01.md) |

## Operating order

1. Filter your territory in the workbook (`country_region` column E, `tier` column V, Tier 1). Check whether any institution appears twice.
2. Pick one target and verify its data at source.
3. Pick one thing to offer — Business Track or developer conference, never both.
4. Pick one thing to ask.
5. Write the relevance sentence and create the pitch file from [`PITCH_TEMPLATE.md`](PITCH_TEMPLATE.md).
6. Call them; mail only if a call is not possible.
7. Send the handout only if they ask for details.
8. Record the outcome in the CSV — the only tracker.

## Product separation

“Both” in the CSV means choose the product that fits the reader. It does not mean send two invitations.

- **Regular technical conference:** exact technical programme relevance for practitioners.
- **Friday Business Track:** decisions about digital autonomy, practical AI, public reuse, governance, procurement and suppliers. English, with no prior Plone knowledge required.

## Non-negotiable boundary

A relationship, directory entry, newsletter subscription or public inbox does not by itself grant authority, endorsement, member access, an introduction or forwarding permission. Ask once, record the exact answer and stop when the answer is no or silence.

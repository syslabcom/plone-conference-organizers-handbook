# ploneconf-accounting

Shadow bookkeeping for Plone Conference 2026 — a one-off event run as a
self-contained business unit inside Cosent's regular company channels.

Two coupled needs served by one hledger setup:

1. **Living budget** — a forecast that converges on actuals as the event
   unwinds. Modelled as a periodic-transaction budget in
   `budget.journal`; compared against actuals by `hledger balance --budget`.
2. **Shadow double-entry ledger** — factual income and cost tracked
   independently of the parent company's SnelStart, structured to produce
   the figures the accountant needs for the BTW return.

**Design doc (authoritative):** `~/org/roam/agentic/devops/ploneconf-accounting.org`
— principles, chart of accounts, entry patterns, BTW mapping, worked example.

**Operator runbook:** [`docs/operator-runbook.md`](docs/operator-runbook.md) —
import cycle, reports, troubleshooting.

## Layout

```
main.journal        # top-level; includes the four files below
accounts.journal    # commodity, decimal-mark, chart of accounts
imported.journal    # generated by `hledger import`; do not edit by hand
manual.journal      # hand-entered transactions (invoiced income, costs, VAT clearance)
budget.journal      # periodic-transaction budget (living forecast)

rules/
  tito-orders.csv.rules       # ti.to orders CSV → 5-posting sale entry
  stripe-payouts.csv.rules    # Stripe payouts CSV → 2-posting transfer
  bin/tito-preprocess.awk     # adds computed columns (arithmetic hledger cannot)
  bin/stripe-payouts-preprocess.awk   # normalises `,` decimal mark to `.`
  .latest.*.csv.rules         # hledger import state cursors (committed)

tests/run-tests.sh  # smoke tests against the worked example
source-data/        # CSV exports, invoice PDFs, supplier receipts
```

## Quick check

```
bash tests/run-tests.sh
hledger -f main.journal balance --budget -p 2026
```
